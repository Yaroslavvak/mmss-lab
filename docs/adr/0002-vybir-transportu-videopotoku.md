# ADR-0002. Вибір протоколу передачі живого відеопотоку

## Статус
Прийнято, 2026-09-25

## Контекст
Вимога NFR-01 обмежує затримку показу до 150 мс, а NFR-05 вимагає обов'язкового шифрування. Стандартний протокол HLS дає затримку від 2 секунд, що забагато для охорони.

## Варіанти
1. HLS через HTTPS - проста інтеграція, але висока затримка (понад 2 с).
2. RTSP через TCP - надійна доставка без втрат, але через повтор передач зростає затримка при збоях мережі.
3. WebRTC / SRTP поверх UDP - мінімальна затримка (< 100 мс), вбудоване шифрування та стійкість до втрат окремих пакетів.

## Рішення
Обрано варіант 3.

## Наслідки
* **+** Затримка відео вкладається в норму до 150 мс (NFR-01).
* **+** Дані зашифровані за стандартом NFR-05.
* **-** Можливі поодинокі артефакти на відео при втраті UDP-пакетів (допустимо до 0.5%).
* **-** Потрібне налаштування портів у корпоративній мережі.
